RQ1-RQ5 Summary

  • RQ1 (OOD generalization): TRACE consistently improves ranking quality under distribution shift.
  • RQ2 (stability): temperature-regulated optimization reduces sensitivity to noisy pseudo-negatives.

  • RQ4 (biophysical coherence): predicted candidates align better with downstream docking-based validation.
  • RQ5 (calibration): probabilistic outputs are substantially better calibrated than baseline objectives.
