Workflow

TRACE example analysis follows a theory-aligned pipeline:

  1. Prepare fixed split data and initialize the dual-branch representation model.
  2. Apply confidence-weighted risk rectification under UaN contamination.
  3. Optimize with thermodynamic regulation and margin-aware contrastive loss.
  4. Evaluate ranking quality, robustness, and calibration jointly.
python scripts/run_trace_e1.py --config configs/trace_e1.yaml --out outputs/run_demo_001
python scripts/check_trace_repro.py --run outputs/run_demo_001 --golden golden/trace_e1_golden_summary.csv --tol 1e-12
