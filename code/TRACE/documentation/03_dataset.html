Input Data

  • data/SMRTnet_main_repro.csv: RNA-ligand interaction candidates and features.
  • data/splits/smrt_5fold_seed7.csv: fixed 5-fold partition with seed 7.

UaN Labeling Scenario

In TRACE, unlabeled pairs are not assumed to be true negatives with certainty. The training objective explicitly accounts for this epistemic uncertainty through confidence-aware weighting and contrastive constraints.

Output Artifacts

  • Prediction-level outputs: raw/trace_e1_raw.csv, raw/trace_predictions.csv
  • Summary-level outputs: summary/trace_e1_summary.csv, summary/trace_e1_diff_vs_golden.csv
  • Reliability and reproducibility checks: checks/gate_report.json, checks/repro_check.json
